# 课程与 Panda 验证记录

日期：2026-10-17。本文记录本机新增课程后的验证，首次框架记录保留在 [framework.md](framework.md)。

## 1. 环境与资源

- Windows：Node.js 24.13.1、npm 11.8.0；前端 TypeScript 检查和 Vite 生产构建通过。
- WSL 默认发行版名称 `Ubuntu-22.04`，其中 Python 3.12.3；Linux 虚拟环境独立安装锁定的 MuJoCo 3.16.0 及项目依赖。
- Windows Chrome 通过 localhost 访问 WSL 服务和查看器动态端口。
- Panda 模型来自 Menagerie 提交 `62ab00f2bc44f6f20c1c9b7a13f3fb1dd41a4e35`。71 个模型、来源、说明和许可证文件均可被 Git 收录；为源模型的 OBJ 网格显式覆盖了根目录的编译目标忽略规则。

## 2. 自动验证

最终执行 `python -m unittest discover -s tests -v`，21 项通过，日志保存在本机忽略目录 `.runtime/course-tests.log`。

覆盖课程与实验引用、课时内容、数值记录保存与读取、非法参数、Panda 状态与执行器初态恢复、雅可比与有限差分一致性、可达及不可达 IK、位置伺服的动力学跟踪、重力补偿对照、轨迹参考与跟踪、真实接触抓取，以及原有单摆、落球、API 和会话生命周期检查。

Studio 专项检查验证 100% 速度的百分数换算、暂停下精确推进一个 1 ms 步，以及命令文件暂时不可读后继续执行和确认请求。状态文件暂时不可读时保留最近有效观测的行为也有回归测试。

## 3. 数值结果

| 最终方块位置 | 约 `(0.450080, -0.199897, 0.224928)` m |

抓取首次实现采用阶段目标突变，实测转移中滑移导致放置失败。改为阶段内五次关节插值后，上述固定初态测试通过。结果只对应当前场景和参数，不证明任意目标或摩擦条件下都能完成任务。

## 4. 浏览器实测

- 课程目录显示 Panda 八节课与基础物理两节课，课时切换时讲解、公式和控件同步更新，并结束旧会话。
- 实际输入关节 1 目标 `0.3 rad` 并应用，仿真状态返回 `0.3 rad`，末端位置随之改变。
- 逆运动学课在网页启动后显示收敛状态、迭代次数和实际残差，三维模型加载成功。
- 抓取课通过网页启动、执行并完成约 16 s 的操作，实时观测显示“已抬升：是、放置成功：是”，方块位于绿色放置区域，查看器继续运行。
- 1800 px、1600 px 桌面布局和 390 px 窄屏布局均检查。390 px 页面没有横向溢出，原理与实验可以切换；官方查看器面板在窄窗口中仍会压缩三维区域，完整操作建议桌面浏览器。
- 原有基础物理课程保留在导航中；其数值计算由原有回归测试验证。

浏览器验收暴露 DrvFS 中命令文件被替换时，`is_file` 与随后 `stat` 之间的竞态会使查看器退出。最终改为直接读取、暂时失败后重试、按请求标识去重。修复后重新完成网页抓取，未再次出现该退出。原子文件通道仍属于本地单用户部署实现，尚未验证网络文件系统或多用户并发。

## 5. 当前适用范围

几何课直接设置构型，动力学课才通过执行器与积分推进。IK 课只约束位置，未包含碰撞避障。抓取为固定场景的规则任务，未接入 AI。课时完成标记由用户手动维护。

独立记录可保存并读取；交互观测导出尚不支持恢复完整仿真、控制器和官方查看器编辑历史。人形机器人、任意模型组合、完整教学评价与远程部署尚未实现或验证。
