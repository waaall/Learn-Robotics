# G1 人形课程验收

日期：2026-10-18。实现与资源版本见 [课程设计](../design/humanoid.md)。

## 自动验证

Windows 和 WSL 均通过 45 项完整回归测试，包含原有 Panda、基础物理、API、会话及新增九项人形测试。前端 TypeScript 检查和 Vite 生产构建通过。最终测试日志位于本机忽略目录 `.runtime/humanoid-tests-windows.log` 和 `.runtime/humanoid-tests-linux.log`。

新增验证覆盖：

- 官方 TorchScript 的 128 步循环推理对照与记忆重置；本机最大动作差约 `1.00e-5`，测试容差为绝对、相对各 `2e-5`。
- 浮动基座维度 `nq=19`、`nv=18`、`nu=12`，以及默认质心跟随相机。
- 暂停改目标不覆盖位置、速度、时间；运动中改目标保留参考位置、速度、加速度。
- 六秒默认站立保持、实际足底接触凸包与左右脚支撑力总和；支撑力总和与全身重力相差小于 2 N。
- 真实动力学中的下蹲、策略启动、行走和减速，保留循环记忆。
- 连续外力包络、载荷修改保留实际状态、恢复初态还原质量和策略记忆。
- 五节课均可独立运行；默认六秒验证均无跌倒采样，抗扰课第 4 s 的实际外力峰值大于 19 N。
- 非法参数原子校验与 HTTP 422；Studio 暂停、2 ms 单步、策略和课程操作校验。

保留已有前端包体积提示与 Starlette 测试依赖弃用提示。

## 数值观测

| 试验 | 结果 |
| --- | --- |
| 默认关节 PD 站立 10 s | 基座高度约 0.7823 m，未跌倒 |
| 默认静止末段左右脚支撑 | 约 157.6 N、157.4 N |

上述结果对应固定版本、当前场景及具体初态，不代表其他摩擦、载荷、指令或外力组合的成功率。

## 浏览器与实际 Studio 通道

Windows 浏览器访问 WSL 服务和官方 WebViewer，实际完成以下操作：

- 课程目录显示人形五节，切课结束旧会话，Panda 七节与基础物理两节保留。
- 第一节暂停后将下蹲目标改为 0.15 rad：返回观测的关节位置、关节速度、基座位置和时间增量均为零。单步时间增量约 0.002 s；随后继续四秒，膝关节实际约 0.4519 rad，目标 0.45 rad，基座高度约 0.7736 m，未跌倒。
- 第四节通过按钮启动策略，实际观测显示 12 维动作、非零位移和稳定基座高度。点击平滑减速后，速度命令降至零；策略保持运行，未跌倒，允许存在原地踏步与实际速度波动。
- 第五节通过按钮启动策略、施加默认平滑外力，实际会话继续运行且未跌倒。质心跟随相机在位移超过 4 m 后仍显示机器人。
- 1600 × 1000 桌面检查查看器、观测、参数及操作区。390 × 844 页面 `scrollWidth=390`、`innerWidth=390`，无横向溢出，页面没有错误提示。

本机截图位于忽略目录 `.runtime/g1-structure-desktop.png`、`.runtime/g1-recovery-desktop.png`、`.runtime/g1-mobile.png`。官方查看器的控制连接状态浮层仍由上游客户端呈现。

## 未验证事项

没有真机部署、策略训练、跌倒起身、完整上肢控制或任意模型组合的验收结论。载荷只修改机身质量，不模拟独立载荷几何与惯量。静态几何距离不作为动态行走稳定性判据。附加载荷、低摩擦、极限指令和强扰动的组合需要单独定义条件并验证。
