日期：2026-10-27。MuJoCo 3.16.0，2 ms 物理步，50 Hz 策略更新。正式回归和网页查看器验收在已有 `robotics-lab:0.1.0` Linux AMD64 容器中挂载本次源码及构建后的前端执行；本机 Windows 环境用于模型与策略的数值检查。未使用 Windows 查看器兼容层。

头部偏航能达到默认目标 0.25 rad 附近；稳定双脚支撑合力约 7.23 N，与全身重力相符。坐站最低高度低于 0.075 m，最后站起高度高于 0.105 m。默认 1 N 外力波形在物理线程记录，施力结束后归零。

官方 ONNX 归一化及权重导出的 NumPy 网络与 ONNX Runtime 固定随机输入对照：Linux 容器中当前选用的 `alpha_walking` 最大绝对误差约 4.77e-7，`alpha_sitstand` 约 9.54e-7。正式回归阈值为绝对误差 5e-6、相对误差 2e-5。参数以 `allow_pickle=False` 加载。

## 浏览器验收

课程目录显示 Microduck 六节，原有 Panda、人形与基础物理课程继续存在。官方 WebViewer 实际加载模型和网格，网页同步显示关节、基座、倾角、左右脚承重。暂停后时间保持，单步推进一个物理步。行走按钮启用官方策略后，页面显示 0.3 m/s 命令、实际速度、交替承重和持续位移。坐下按钮将姿态标志设为 1，页面基座高度降至约 0.060 m；站起按钮设为 0，高度回到约 0.116 m。

## 已观测限制

`Kp=200` 的纯关节位置环未能维持默认站姿，基础课和行走启动前使用课程 `Kp=800`；学习策略运行时恢复官方 `Kp=200`。`velstand` 和行走专用策略在低速指令下都可能主要保持站立，默认 0.3 m/s 用于显示可观察的行走。实际速度低于指令，不能据一次课程运行宣称精确速度跟踪。

坐站策略中，姿态标志在 0 和 1 之间插值会延迟坐下并导致站起倾倒；使用离散标志后完成默认坐站过程。输入标志离散切换，物理位置、速度与时间仍连续。

未进行实机验证、长时稳定性基准、多随机种子成功率、齿隙与延迟随机化训练，或平台内 PPO 训练。本记录只描述当前适配与默认条件下已完成的验证。
