# Robotics Lab 整体需求

中文名称：机器人交互实验室。

文档日期：2026-10-17。

文档状态：长期产品需求初稿。本文描述计划最终实现的使用能力和验收预期，不表示相关功能已经完成；各项能力的实际完成情况由后续验收记录说明。

## 1. 项目定位与目标

Robotics Lab 是面向机器人学习、交互演示和实验分析的长期平台。用户能够结合中文讲解、公式、可操作的机器人仿真和实验数据，研究机器人的结构、运动、受力、控制及 AI 策略。

平台以具体问题和可重复的实验组织内容。用户可以调整条件、运行计算、观察结果，并将结果与理论预测或其他方法进行比较。

最终希望实现以下目标：

1. 系统组织机器人知识，说明各模块的输入、输出、职责和相互关系。
2. 将理论概念与可交互实验对应，使用户能够观察参数变化如何影响机器人行为。
3. 提供统一的机器人、环境和实验入口，减少重复准备实验的操作。
4. 支持运动学、动力学、接触、控制和 AI 策略的学习与对照分析。
5. 积累可保存、可复现、可扩展的实验配置、结果和学习材料。

## 2. 使用对象与主要场景

主要使用对象是学习机器人原理、研究算法实现并进行仿真实验的用户。内容应支持从基础概念逐步进入控制和学习策略研究，并说明每个实验需要的前置知识。

| 使用场景 | 用户希望完成的事情 |
| --- | --- |
| 概念学习 | 阅读概念、变量和公式，操作对应实验，观察计算过程与物理意义 |
| 机器人观察 | 选择机器人，检查结构、关节、执行器、坐标系和物理参数 |
| 参数实验 | 改变初始状态、负载、输入、摩擦或控制参数，比较运动和受力变化 |
| 算法研究 | 在适用任务中运行不同控制器或 AI 策略，观察输入输出与执行结果 |
| 结果分析 | 查看轨迹、曲线、数值指标和失败过程，定位误差或不稳定的原因 |
| 实验复现 | 保存实验条件与结果，重新载入，并在相同条件下进行对照 |

## 3. 完整使用流程

平台应支持以下连续操作：

1. 浏览知识主题，或从机器人目录进入。
2. 选择机器人，了解其结构、可用场景和已适配实验。
3. 选择环境、任务和实验目标。
4. 阅读前置知识、原理、预期现象及需要观察的物理量。
5. 配置初始状态、物理条件、控制方式和实验参数。
6. 运行仿真，进行暂停、单步、速度调整、参数修改或交互施力。
7. 同时观察机器人运动、坐标系、物理量、曲线和实验指标。
8. 对照理论预测、基准配置或其他方法，分析结果。
9. 保存实验配置和运行记录；需要时恢复初态、回看或再次运行。

用户应能从知识页面进入相关实验，也能从实验中的变量、现象和结果返回对应讲解。

## 4. 机器人目录与模型观察

### 4.1 机器人选择

- 以缩略图和名称展示机器人，支持按机器人类型和实验能力筛选。
- 长期覆盖机械臂、夹爪与灵巧手、移动机器人、足式机器人以及适合基础教学的简化机构。
- 每个机器人展示来源、适用版本、自由度、关节类型、主要物理参数和可用实验。
- 明确区分模型可以加载、可以受控运动、已经适配任务及完成定量验证等状态。
- 机器人、环境和实验的可选组合应反映实际适配情况；不兼容的组合应说明原因。

### 4.2 结构与参数观察

- 支持查看刚体、关节、执行器、传感器及其连接关系。
- 支持显示和选择坐标系、关节轴、末端参考点、质心及其他实验相关标记。
- 支持观察质量、惯量、关节范围、控制范围和接触相关参数，并说明单位与物理意义。
- 说明物理模型描述的结构和参数，以及 AI 策略使用的观测和动作，避免混淆两类模型的用途。
- 对参数来源、估计值和未校准项作出说明，便于解释仿真结果的适用条件。

## 5. 环境、任务与实验配置

### 5.1 环境与任务

- 提供基础地面、桌面、操作物体、障碍物等可复用环境要素。
- 支持在已适配的环境中选择机器人初始位置、目标位置、操作对象和任务条件。
- 任务应说明目标、成功条件、失败条件、终止条件和评价方式。
- 机器人与环境之间的接触、传感器和控制条件应能被用户查看。

### 5.2 实验配置

- 将机器人、环境、任务、初始状态、控制方式和观测指标组织成一个完整实验。
- 提供默认配置，并支持用户保存和恢复自己的配置。
- 参数应说明名称、单位、允许范围和含义；必要时显示与公式符号的对应关系。
- 参数修改后应明确反馈生效方式：立即作用、恢复初态后作用，或重新加载实验后作用。
- 支持恢复实验初始状态和默认参数，避免交互修改后无法重复原实验。
- 对不支持、超出范围或相互冲突的配置，给出具体原因和可执行的调整建议。

## 6. 核心实验需求

### 6.1 运动学

学习目标是理解关节状态、机器人构型、末端位姿和运动速度之间的关系。

用户应能够：

- 调整关节角度或位移，观察机器人构型和末端位姿的变化。
- 查看世界、刚体、关节和末端坐标系之间的关系。
- 设置末端目标，运行已适配的逆运动学实验，观察求解结果及目标误差。
- 调整关节速度或末端速度目标，观察雅可比所表达的速度映射。
- 观察关节限位、奇异构型和不可达目标对运动或求解结果的影响。
- 查看末端轨迹，并把位姿与速度结果对应到公式中的变量。

系统应区分直接设置构型与通过控制输入驱动运动，使用户能够判断当前观察的是几何关系还是动力学过程。

### 6.2 动力学

学习目标是理解质量、惯量、重力、速度相关作用和关节耦合如何决定运动。

用户应能够：

- 施加关节力矩或外力，观察位置、速度和加速度的变化。
- 修改适用实验中的质量、惯量、末端负载和重力条件，比较响应差异。
- 查看质量矩阵、相关力项和关节耦合，并与运动结果对应。
- 运行重力补偿等实验，观察补偿输入和残余运动。
- 比较仿真结果与适用简化模型的解析预测。
- 调整步长等数值实验条件，观察积分误差、稳定性及能量变化。

相关实验应记录理论比较的假设和适用条件，并分别说明物理参数误差与数值计算误差。

### 6.3 接触与摩擦

学习目标是理解碰撞、法向支撑、摩擦、滑动以及接触参数对机器人交互的影响。

用户应能够：

- 运行落体、支撑、滑动、推物和抓取等已适配接触实验。
- 查看接触位置、法向、接触力及其变化。
- 调整摩擦和接触响应参数，对比接触过程与稳定状态。
- 对物体施加可控扰动，观察滑动、接触变化和恢复过程。
- 查看物体间隙、几何穿透量、滑动速度和支撑力等指标。
- 对照不同参数配置，分析接触现象及其数值表现。

系统应说明显示的接触量及参数含义，区分接触记录、实际约束作用、冲击过程和稳定支撑。

### 6.4 控制

学习目标是理解控制目标、反馈、控制输入和机器人实际响应之间的关系。

用户应能够：

- 设置关节位置、速度、末端目标或参考轨迹，运行对应的控制实验。
- 调整 PD 增益，观察跟踪速度、误差、振荡和控制力矩。
- 修改负载、加入外部扰动，观察控制器的响应与恢复过程。
- 比较重力补偿、不同增益及输入限幅对执行结果的影响。
- 查看参考量、测量量、误差、控制输入和实际运动之间的对应关系。
- 在后续适配实验中研究力控制、柔顺控制和其他控制方法。

控制输入必须说明实际物理含义，例如关节位置目标、速度目标、末端目标或力矩，并显示相关约束。

### 6.5 AI 策略

学习目标是理解 AI 策略接收什么观测、输出什么动作，以及动作如何引起机器人和环境的变化。

用户应能够：

- 选择已经适配机器人与任务的策略，查看其来源、适用条件和运行要求。
- 查看策略使用的状态、图像、任务指令等观测，以及对应的动作输出。
- 了解动作的单位、参考系、时间含义和执行方式。
- 运行策略，观察动作序列、任务过程、失败情况和评价指标。
- 调整已开放的任务条件、初始状态或扰动，比较策略表现。
- 查看观测更新、策略输出和物理执行的时间关系。
- 在适合比较的任务中，对照 AI 策略与传统控制方法，并说明两者承担的任务和控制职责。

策略适配应说明动作后续经过哪些执行环节，例如目标转换、关节跟踪和输入限幅。对未适配的机器人、任务或观测形式，应明确说明缺少的条件。

### 6.6 核心实验的观察结果

| 实验主题 | 主要用户操作 | 重点观察结果 |
| --- | --- | --- |
| 运动学 | 调整关节、设置末端或速度目标 | 末端位姿、坐标系、雅可比关系、轨迹与求解误差 |
| 动力学 | 修改负载、施加力矩或外力 | 加速度、质量矩阵、重力补偿、关节耦合与能量变化 |
| 接触 | 修改摩擦和接触参数、施加扰动 | 接触力、滑动、穿透量、支撑与碰撞过程 |
| PD 控制 | 修改目标、增益、负载和限幅 | 跟踪误差、振荡、控制力矩与扰动恢复 |
| AI 策略 | 载入适配策略、修改任务条件 | 观测、动作、执行过程、成功率及与其他方法的对照 |

## 7. 仿真交互与过程观察

- 支持运行、暂停、单步、播放速度调整和恢复初态。
- 支持相机旋转、平移、缩放、目标跟踪，以及适合实验的预设视角。
- 支持选择机器人部件，查看其名称、状态和实验相关属性。
- 支持在适用实验中通过交互方式施加扰动力，并查看施力对象、方向和大小。
- 支持按实验需要显示坐标系、关节轴、轨迹、目标、接触和力等信息。
- 支持区分仿真时间、显示速度和控制更新时刻，避免混淆不同时间含义。
- 支持记录和回看实验过程；区分查看历史状态、恢复状态及从该状态重新运行。
- 回看或恢复涉及控制器与策略内部状态时，应说明恢复了哪些内容，以及是否满足继续实验的条件。

## 8. 中文讲解与知识组织

### 8.1 实验讲解

每个教学实验应包含：

1. 要研究的问题和学习目标。
2. 前置知识、适用机器人、环境及结构假设。
3. 核心概念、公式、变量、单位和参考系。
4. 用户操作与参数说明。
5. 预期观察现象和结果分析方法。
6. 可比较的配置或方法，以及常见失败现象。
7. 来源、适用版本和未验证事项。

讲解应与可操作控件和可观察物理量对应。用户选择参数或曲线时，应能找到相关变量说明；阅读关键概念时，应能进入对应实验。

### 8.2 长期内容体系

核心内容围绕运动学、动力学、接触、控制和 AI 策略持续完善。在此基础上，长期扩展以下主题：

- 机器人结构、执行器、传感器和观测过程。
- 轨迹生成、运动规划、避障与任务组织。
- 感知、状态估计、定位和导航。
- 模仿学习、强化学习和视觉语言动作策略的原理及任务实验。
- 移动操作、足式运动、全身协调和多接触任务。

扩展主题应有相应的讲解、可运行实验和结果分析方法。具体实验及验收条件在对应主题需求中继续细化，不以仅增加一个目录条目作为该主题完成的依据。

## 9. 数据、对照与实验报告

### 9.1 数据观察

- 同时展示三维运动、关键数值和时间曲线。
- 位置、速度、加速度、控制输入、接触力和任务指标应说明单位、参考系及采样时刻。
- 支持选择曲线、调整观察范围，并定位关键事件对应的状态。
- 对齐同一时刻的状态与派生量，说明数据经过的滤波、降采样或其他处理。

### 9.2 对照实验

- 支持比较不同参数、控制器、策略和重复运行结果。
- 对照时展示机器人、环境、初态、目标、输入约束和评价条件的差异。
- 对适合重复评价的任务，展示运行次数、成功与失败记录，以及指标的统计结果。
- 对没有统一动作接口或承担不同职责的方法，说明比较目标与额外执行环节。

### 9.3 保存与复现

- 保存机器人与环境来源、适用版本、初始状态、参数、控制器或策略标识、指标定义和运行结果。
- 涉及随机过程时，记录相关随机条件；说明结果的可重复程度。
- 支持重新载入已有实验配置，复现操作条件，并与原始结果比较。
- 支持导出配置、数据、图表和实验报告，便于后续研究和交流。
- 报告应包含目标、条件、操作、观测、评价结果和适用限制，并区分实测结果、理论预测和推断。

## 10. 运行与使用要求

- 支持在用户本机运行，并通过浏览器访问统一入口。
- 所需资源准备完成后，核心学习、仿真和结果查看功能应能够离线使用；资源缺失时说明缺少的内容。
- 对每项实验说明已验证的使用环境和必要条件。
- 运行状态、暂停状态、资源加载和实验失败应有清楚反馈。
- 实验运行期间应能响应用户的暂停与终止操作；失败后能够重新选择或恢复实验。
- 保存的配置和结果应便于用户查找、识别与再次使用。
- 能力、内容和验证状态应随项目演进更新，支持持续增加机器人、场景和实验。

## 11. 整体验收预期

长期平台的核心能力应满足以下可观察标准：

| 编号 | 验收预期 |
| --- | --- |
| A01 | 用户能通过缩略图或主题目录选择机器人、环境与已适配实验，并进入相应讲解和操作界面 |
| A02 | 运动学、动力学、接触、PD 控制和 AI 策略五类主题均有至少一个可运行、可分析、可复现的完整实验 |
| A03 | 用户调整实验参数后，能观察行为变化，并找到相关物理量、曲线和理论说明 |
| A04 | 用户能暂停、单步、恢复初态、施加适用扰动，并回看已记录过程 |
| A05 | 核心指标具有明确的单位、参考系、时间含义和评价条件，相关量能够与实验状态对应 |
| A06 | 适用实验能比较理论与仿真、不同参数或不同方法，并说明比较条件与差异 |
| A07 | AI 实验能展示观测、动作及后续执行关系，说明策略适配对象和任务评价结果 |
| A08 | 已保存的实验包含重新运行所需的条件，用户能重新载入，并分析与原结果的差异 |
| A09 | 资源准备完成后，核心流程可在已验证的本地环境中离线完成；缺失资源与不支持条件有明确说明 |
| A10 | 每个已完成教学实验具有中文讲解、操作说明、结果分析依据和验证状态 |

## 12. 后续需要单独明确的需求

以下内容需要在后续主题或使用需求明确后继续细化，不作为当前核心实验能力的默认承诺：

- 策略训练、数据采集、数据标注和训练过程管理。
- 仿真与真实机器人之间的参数辨识、迁移和执行验证。
- 实体机器人连接、遥操作和硬件运行管理。
- 多人协作、远程共享和公开教学服务。
- 各类机器人与长期扩展主题的覆盖顺序、内容深度和定量评价要求。
