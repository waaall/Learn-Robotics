# 课程组织与 Panda 适配

日期：2026-10-17。本文描述当前课程实现。项目按自身需求独立发展，不导入 `experiments/` 的代码、环境、数据或策略。

## 1. 课程、课时与实验资源

`curriculum.py` 定义课程及有顺序的课时。课时保存研究问题、前置知识、原理与公式、操作步骤、观测、练习、来源和实验引用。`catalog.py` 解析实验模型、初态、时长与适配器。课程内容和运行状态分别保存。

| 课程 | 课时 | 执行方式 |
| --- | --- | --- |
| Panda 机械臂基础 | 机械臂结构与正运动学 | 合并原两节，通过位置伺服连续运动，以实际构型计算末端位姿 |
| Panda 机械臂基础 | 关节位置控制 | 目标角度经过位置与速度反馈，执行动力学 |
| Panda 机械臂基础 | 自重与重力补偿 | 关闭七路伺服，同一静止初态对照关闭补偿释放与开启补偿保持；世界重力始终存在 |
| Panda 机械臂基础 | 雅可比 | 两秒单关节几何运动，对照区间起点的雅可比预测与末端位置差分速度 |
| Panda 机械臂基础 | 逆运动学 | 阻尼最小二乘求位置任务的关节目标，收敛后由位置伺服与动力学连续跟踪 |
| Panda 机械臂基础 | 轨迹跟踪 | 三秒线性或五次关节插值与动力学跟踪 |
| Panda 机械臂基础 | 抓取 | 固定姿态 IK、阶段内五次关节插值、夹爪接触与摩擦 |
| 基础物理实验 | 单摆、落球 | 保留原有动力学和独立数值验证 |

`adapter` 指定实验适配模块。Panda 的七关节、夹爪映射和工具点定义位于 Panda 模块中；课程、课时标识和运行记录接口没有固定关节数量。后续人形课程需要新增相应的浮动基座、接触和控制适配，当前没有人形模型运行或控制能力的验收结论。

Panda 目录共七节。原 `panda-fk` 课时、实验和网页链接映射到 `panda-structure`，不在目录重复列出；浏览器中的旧完成标记归并到第一节。

页面以实验操作为主要工作区：三维查看器位于左侧，课时对应的观测和参数位于右侧，操作按钮与过程曲线位于其下。研究问题、原理、公式、步骤和分析位于实验区下方，顶部提供直接跳转；独立数值验证单独保留在讲解之后。旋转矩阵与完整关节表可展开；雅可比矩阵直接显示并高亮运动关节对应列，起始构型参数折叠展示。

课程目录默认收起，通过顶部按钮展开，展开状态保存在浏览器 `robotics-lab.directory-open.v1` 中；刷新时恢复，存储不可用时仍可操作。桌面展开目录会重新分配主区域宽度，1100 px 及以下使用抽屉；Escape、遮罩或选课可收起抽屉。实验区根据主内容容器宽度切换横向或纵向排列，850 px 及以下按三维实验、观测、参数的顺序展示。

Panda 会话通过 [MuJoCo 3.16.0 ViewerAppConfig](https://github.com/google-deepmind/mujoco/blob/3.16.0/python/mujoco/experimental/studio/viewer_app.py) 将 `show_options` 与 `show_inspector` 初始设为 `False`，保留官方 View 菜单及其面板开关。基础物理会话保留这两个面板，其原有操作控件继续可用。

## 2. 模型来源与场景

上游：[MuJoCo Menagerie，提交 62ab00f2](https://github.com/google-deepmind/mujoco_menagerie/tree/62ab00f2bc44f6f20c1c9b7a13f3fb1dd41a4e35/franka_emika_panda)。复制 `panda.xml` 与 `assets/`，保留上游 README 和 Apache-2.0 LICENSE，来源记录位于模型目录的 `upstream.json`。

`panda_course.xml` 增加地面、桌面、0.08 kg 方块、目标标记与放置区域。绿色目标球是程序指定位置的 mocap 标记，关闭碰撞，仅在 IK 与抓取课显示；放置区域仅在抓取课显示。它们不作为重力观测对象。Python 加入手部局部位置 `(0, 0, 0.1034)` m 的工具点和三个坐标轴。模型加载时显式解析包含文件中的网格路径，并恢复关节状态和执行器目标。独立记录中的模型指纹覆盖场景 XML、Panda XML、网格和来源文件。

固定使用 MuJoCo 3.16.0，物理步长 0.001 s。Panda 模型的 16 个广义位置包括七个转动关节、两个夹爪滑动关节和方块自由位姿；存在 15 个广义速度和 8 个执行器。

## 3. 控制与算法

本版本没有 AI 模型。逆运动学、插值、反馈控制和任务阶段切换均使用明确的传统算法。

机械臂前七路执行器使用上游位置伺服形式：

$$
\tau_i=K_{p,i}(q_{d,i}-q_i)-K_{d,i}\dot q_i
$$

网页分别提供位置增益倍率 $a$ 与阻尼倍率 $b$，对上游参数应用 $K_p'=aK_p$、$K_d'=bK_d$。第一节、位置控制、IK 与轨迹课默认 $a=0.2$、$b=\sqrt{0.2}$；第一节与 IK 课隐藏调参控件，以结构、位姿及求解观测为主。旧 API 记录只提供 `gain_scale` 时保留 $b=\sqrt a$ 的配对规则，显式提供 `damping_scale` 后可独立调节。力矩受上游执行器限幅约束。夹爪目标总开口 $w_d$ 从 `[0, 0.08]` m 映射到上游执行器 `[0, 255]`。

重力补偿由辅助状态在相同构型、零速度条件下求得 `qfrc_bias`，仅将前七个分量作为外加广义力。重力课关闭机械臂伺服，其余动力学课保留位置伺服。补偿不能消除已有速度、接触或外力。

重力课的释放、保持命令均恢复同一关键帧并清零速度、时间和任务状态，再选择补偿并开始运行。观测包括相对初态的关节构型偏移范数、末端高度变化、重力项及实际外加补偿力矩；世界重力均为 `(0, 0, -9.81)` m/s²。

雅可比课默认选择关节 2、速度 0.05 rad/s。运行命令设置起始构型，再按速度执行两秒几何运动；到限位时使用截断后的实际关节速度。每个 1 ms 区间以起点 $J_p(q(t))$ 乘实际区间关节速度作为预测，以两端工具点位置差分作为观测。两者通过不同计算过程得到；有限区间误差不要求严格为零。停止后关节速度归零，同时保留最后运动区间的雅可比、速度和误差供检查。网页箭头是世界坐标三维速度的等轴投影，两支箭头使用相同缩放，另显示完整三轴数值；过程曲线在停止后归零。该实验只展示 $3\times7$ 平移雅可比，仍不经过动力学积分。

位置 IK 使用 `mj_jacSite` 对应机械臂的平移雅可比，以 0.02 阻尼迭代，最大 160 次，单次关节增量范数不超过 0.12 rad，并施加模型限位。位置误差阈值为 0.0001 m。本课不约束姿态、不执行碰撞规划；未收敛时保留并显示实际残差。抓取阶段额外固定初始工具朝向。

IK 在辅助 `MjData` 中求解，应用参数不覆盖当前 `qpos`、`qvel` 或时间。收敛后把解写为 `target_q`、`reference_q`，后续通过与第一节相同的位置伺服、重力补偿和 `mj_step` 执行运动。未收敛时不执行候选解，保留上一有效关节目标并明确报告状态。界面分别显示候选解的 IK 残差、当前末端到请求目标的距离及关节参考跟踪误差；曲线同时显示实际和参考角度。暂停时求解只更新目标，单步或继续后才运动；运动中重新求解也保留当前速度。

抓取通过八个时间阶段执行约 16 s 的操作。阶段内使用五次关节插值；没有绑定或吸附物体。方块实际高度超过 0.32 m 记为抬升。阶段结束后，实际平面位置距 `(0.45, -0.20)` m 小于 0.06 m，且高度距 0.225 m 小于 0.02 m，才判定放置成功。该规则任务已针对本场景适配，改变摩擦或状态后可能失败。

## 4. 交互线程与观测

网页通过 FastAPI 向当前会话发送带会话标识的命令。会话管理器串行提交原子 JSON 命令，并等待仿真进程返回相同命令标识；旧会话命令被拒绝。`PandaStudio` 在官方 Studio 的仿真线程内处理参数、重置、暂停和任务启动，API 线程不直接访问 `MjData`。重力对照与雅可比运行命令会恢复运行状态，暂停时也可直接开始；停止雅可比运动会清零速度并保留末次对照采样。

插件按实际时间预算推进积分步，官方速度单位为百分数，100 表示一倍速；单步命令暂停后只推进一个 1 ms 步。观测约以 10 Hz 写入，网页约以 5 Hz 读取，记录近期 400 个采样。调度和显示频率不作为硬实时保证。文件短暂不可读时保留最近有效观测及其时间，网页据数据年龄显示更新状态。

每次成功发布的交互观测包含会话内递增的 `observation_sequence`，暂停和恢复初态均不重置序号，发布时间也不参与排序。网页通过同一状态更新模块处理轮询与命令应答，先校验会话和序号，再更新当前状态与历史；较旧序号被丢弃。同一发布的重复读取仅更新数据年龄，以保留观测停滞提示。较新发布的仿真时间回退时开始新记录；重置、重力对照和雅可比运行命令另按应答序号过滤旧试验采样，即使应答迟于后续轮询，也保留已经收到的新试验观测。切换会话后单独接收新会话的序号。

`/api/system` 的初始查询、周期轮询和启动就绪查询统一经过 `SystemRequests`。打开、结束和切课操作前后递增请求代次并取消旧查询，操作期间只允许本次操作的就绪查询；同一代次按请求序号拒绝迟到响应。组件卸载时使未完成查询与尚未处理的发布失效。课程初始加载使用最近已接受的系统状态，避免较慢的课程响应重新应用旧会话信息。应用级 DOM 测试实际挂载 `App`，通过受控请求延迟核对会话按钮、查看器和导出历史；测试依赖仅用于开发阶段。

几何课的时间表示实验推进时间，构型由几何规则更新；动力学课执行 `mj_step`。外层网页显示实际位置、参考、关节力矩、雅可比或任务结果。Panda 课程使用自身的步进与重置语义，不接入官方历史回退插件；官方窗口主要提供场景观察和相机操作。

## 5. 数据与学习记录

- 交互观测导出包括课时标识、会话标识、网页操作与近期采样；没有完整物理状态和控制器状态回放功能。
- 独立验证使用单独模型、预设初态和网页参数，计算后保存参数、模型指纹、运行库版本、采样、末态和指标。不改变交互会话。
- 课时完成由用户手动标记，保存在当前浏览器的 localStorage 中；不代表自动评价学习结果。
- 前端将 KaTeX 和字体打包到本地，运行时不请求远程公式或字体资源。

## 6. 课时预设与默认观测（2026-10-20）

各机器人适配模块的 `default_settings(mode)` 定义课程预设。课程 API 通过 `default_settings` 字段提供网页表单参数；省略参数的独立计算、网页计算和交互重置使用同一份定义。模型关键帧仍定义实际初态，预设定义要执行的目标与控制参数；修改目标不会将实际状态直接设置到目标。

Panda 结构课默认关节 2 增加 0.1 rad，主曲线显示末端三轴位置并展开旋转矩阵；关节控制课默认关节 1 目标为 0.2 rad，显示实际角、参考、目标与执行器力矩。轨迹课默认终点为关节 1 = 0.3 rad、关节 2 = 0.2 rad，显示三路角度和参考跟踪误差。

结构课的实时观测与独立验证末态另提供默认折叠的关节角表，按返回的关节数量列出实际角、参考角和已应用的目标角，单位均为 rad。表内目标取自观测状态，参数表单中尚未应用的修改不改变该值；末端位置主图保持不变。

轨迹课配置终点时保留正在执行的参考与实际状态，只有执行轨迹命令才从当前实际构型生成三秒轨迹。打开实验或编辑下一次终点均不会提前执行该终点；已启动轨迹保存自己的终点，编辑表单不改写正在运行的轨迹。暂停时执行命令保留暂停，单步或继续后推进。

交互重置恢复关键帧并重新配置课时预设；网页同时恢复表单和默认观测关节。实际状态仍位于初态，后续运动由控制器和动力学产生；轨迹课继续等待执行。重力课的释放、保持按钮保留同初态对照语义。验收见 [课时预设与观测验收](../validation/lesson-presets.md)。
